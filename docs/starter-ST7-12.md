# 스타터덱 ST7 ~ ST12 효과 전수 검증 (문장 단위)

검증 방법: 카드 원문(effectKo / inheritedKo)을 문장 단위로 읽고, Node 하네스에서 실제 경로(`lookupCardSpecific` → `compileToScript` → `runScript`, 트리거는 `queueTriggersForStack` / `emitGameEvent`, 지속 효과는 `effectiveDP` / `hasKeyword` / `hookSecurityAttackBonus`)로 구체적인 보드를 만들어 상태를 단언했다. ST11 은 데이터(cards.json)에 존재하지 않는다.
브라우저: ST10 vs ST9, ST12 vs ST10 스타터(자동 조립 50장) 2판을 uibot 으로 끝까지 진행, 페이지 오류 0, 오작동 로그 없음.

## 미해결 / 범위 밖 메모
- 「X인 자신의 디지몬 전부는 《키워드》를 얻는다」(지속 부여) 계열은 컴파일러가 일회성으로 처리하는 것으로 보인다. 내 범위는 카드별 훅으로 고쳤고, 같은 문구의 다른 카드(P-033, BT1-085, BT3-030, BT5-093, EX1-057, BT8-016, BT10-092, EX3-033 …)는 각 담당 확인 필요.
- BT9-082 「Lv.6 이상 1마리와 Lv.5 이하 전부 소멸」이 Lv.5 이하 전부 소멸만 컴파일됨, BT8-042 「시큐리티 매수 이하의 Lv.」 필터가 누락됨 (범위 밖).
- 배치 UI 의 `required:false` 선택창(ST10-06 트래시 카드 선택 등)은 강제 효과여도 취소 가능하게 표시될 수 있음.

# 카드 효과 검증 — BT7 / BT8 / BT9 (batch 3)

검증 방법: 실제 state/engine 함수로 보드 구성 → 효과 실행/트리거/지속효과 probe → 인쇄 텍스트와 대조. (기존 verify-*.md 에 있는 카드는 제외)

## 공통 수정
- 「테이머를 Lv.N 디지몬으로서 취급하여 (진화 코스트 X를 지불하여) 진화」 — 패의 하이브리드체 카드(BT4/6/7)는 진화 자체가 불가능했음 → engine.evolutionMethods `tamer-as-digimon` 추가 + main.js 가드 완화 (BT7-112 는 10장 덱 아래 지불 포함 `tamer10`)
- 「자신의 「X」는 진화조건을 무시하고 진화 코스트 N을 지불하여 패의 이 카드로 진화」 (BT5-014/067/111, BT7-017/111, EX2-022) — state.evolveTargetRestriction 에 일반 파서 추가
- 「자신의 효과로 이 카드가 패로부터 파기되었을 때」 (BT6-078/108, BT7-072/076/077) — queueOwnDiscardTriggers 가 '패로부터'/'자신의 효과로' 접두를 인식하지 못함 → 수정
- 「진화원에 테이머 카드를 갖는 …패의 이 카드로 진화할 때 코스트 -2」 (BT7-014/025/038/051/075) — selfEvoDiscount 훅
- 「자신의 시큐리티 디지몬 전부 DP+N」【상대의 턴】 (BT7-042/088; 미처리 카드: BT4-045, EX1-031 은 타 배치 확인 필요)

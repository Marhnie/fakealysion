## 범위
- 특징 CS 카드 141장, 텍스트에 「CS」가 나오는 카드 131장 전수 조사.
- 〔진화〕 `특징 「CS」를 가진 Lv.N : 코스트 X` 계열 95줄(OR 이름/OR 특징/이름 포함 OR 포함), 〔조그레스〕 4장(BT22-015, BT23-032, BT23-047, BT23-102), 효과 진화(진화시킬 수 있다 / 블래스트 / 코스트 -N), 색 조건 무시 옵션 10장.

## 엔진/UI 경로 검증 (문제 없음)
- 95줄 모두: 해당 Lv의 CS 카드 전부(색 무관, Lv.2 디지타마 카테고리 포함)가 인쇄 코스트로 진화 방법에 나옴. 육성 에어리어 Lv.2 → Lv.3, 색이 다른 소스, 코스트 그대로 `S.digivolve`로 메모리 차감 확인.
- 비CS 같은 Lv는 CS 줄을 못 씀 / 맨 위 카드가 비CS이고 진화원에만 CS면 불가(맨 위 카드 기준).
- 일반 진화와 CS 줄이 동시에 만족되면 선택 모달에 두 방법(일반 진화 / 특수 진화 조건)과 기본·효과 반영 코스트가 표시됨(브라우저 실제 drag 확인: 와냐몬→테리어몬 코스트 1/0, 알포스브이드라몬→오메가몬 6/5).
- 브라우저(드래그): Lv.2 육성→Lv.3, Lv.3→Lv.4(다른 색, 메모리 10→8), Lv.5→Lv.6(→7), Lv.6→Lv.7 코스트 5(→5), OR 이름(「코로몬」/CS), OR 특징(「화염형」/CS) 통과; 비CS·진화원만 CS는 거부.
- 진화 코스트 보정: BT22-031/BT23-037 (CS로 진화 -1, 턴 1회), 진화 -2/-3 효과(BT22-037/090/101, BT23-053, BT23-076), 무료 진화(BT22-065, BT23-036, BT22-004 -1) 정상. 〔조그레스〕 4장 파싱/판정 정상.

## 발견 및 수정한 버그
1. **한 줄에 이어 붙은 〔진화〕 조건 누락** (BT22-063 알파몬, BT22-067 로드나이트몬 등 37장): `코스트 3/자신의 시큐리티가 3장 이하인 동안, 「쿠레미 쿄코」 : 코스트 5` 의 뒤쪽 조건이 사라짐. `src/engine.js parseEvoConditions`가 동시 작업 중 이미 수정됨(다른 에이전트) — 이 회귀 테스트(2번 섹션)로 확인.
2. **BT22-043 / BT26-054 감시 효과 미등록** ("이 디지몬의 진화원에 특징 「CS」를 가진 디지몬 카드가 효과로 놓였을 때" — BT22-043: 테이머 등장, BT26-054: 【서로의 턴】 CS 카드로 무료 진화): 트리거 자체가 발동하지 않았음. 신규 `src/cards/shard47.js` (index.js 등록)에서 sourcesAdded 훅 추가.
3. **P-225 디지랩 / P-238 디스트로이 캐논 색 조건 무시 미적용**: "…디지몬/테이머가 있다면 색 조건을 무시하고 사용할 수 있다"(P-225)와 `<사용 조건(특징 「CS」)>`(P-238) 표기를 `S.optionColorOk`가 인식하지 못해 CS 디지몬이 있어도 사용 불가. `src/state.js optionColorOk` 두 정규식 확장.

# verify-reveal-3 (배치 3: 150 세그먼트, 덱 오픈/서치 계열)

검증 방식: (1) 인쇄 텍스트 vs 컴파일 결과 전수 대조, (2) 카드별 Node 시나리오(덱 순서 고정, 매칭/비매칭 혼합, 선택 스크립트) —
공개 장수, 선택 가능 카드(비매칭 제시 여부), 이동처, 나머지 처리(위/아래/파기, 순서 선택), 덱 카드 수 보존, 후속 효과.
핵심 하네스: scratchpad t3.mjs(자동 143장: 미매칭 시 아무것도 안 집음 / 매칭만 제시 / 카드 소실 없음), t3s_all3.mjs(개별 시나리오 57건 PASS).

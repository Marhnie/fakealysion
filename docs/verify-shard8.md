# Shard 8 검증 로그 (BT25/BT26/ST23/ST24/EX12)

하네스: scratchpad `s8h.mjs` (rich/board/seg), `run1.mjs`(전 세그먼트 스모크), `t_*.mjs`(카드별 시나리오).
방식: 인쇄 텍스트 vs 구현을 대조하고 실제 S/E 함수로 보드를 구성해 전/후 상태를 비교.

## 수정 사항 요약
| 카드 | 문제 | 조치 |
|---|---|---|
| BT25-069 | 트래시의 「TS」 카드가 옵션(링크 옵션)이라 `S.linkCheck`가 category 검사로 거부 → 효과가 항상 무변화 | `S.linkCheck(…, {allowOption})` 추가, s8_link에 `allowOption` 전달 |
| BT26-086 | 단테몬 자신은 「어플몬」이 아니라 링크 조건 불일치 + 룰체크(17-1-3-2-6)가 링크 카드를 파기 + 자체 《링크 +6》 무시(상한 1) | `ignoreLinkCond` 옵션(조건 무시, 룰체크 면제 플래그), `linkCapOf()`가 카드 자체의 《링크 +N》 반영 |
| EX12-072 | 서로의 턴 《수호》 부여가 스크립트만 있고 훅이 없어 실제로 발동 안 함 | HOOKS `grantKw`로 교체 |
| BT25-086 | 상대 메모리 0이면 DP+0이라 대상 미기록 → 이후 "그 디지몬으로 어택" 불가 | s8_dp가 +0이어도 대상 기록 |
| BT25-088 | 옵션 카드 사용에도 등장 코스트 -1이 제시됨 (텍스트는 "등장할 때") | 옵션 제외 |
| 테이머 아래 「뒷면」 | 비용 판정이 뒷면 여부와 무관(sources.length) | `S.fdCount` 기준으로 변경 |
| EX12-044/032 | "Lv.이 같은 카드가 2장 이상 겹쳐져" 를 본체 Lv 기준으로만 판정 | 진화원 중 같은 Lv 2장 이상으로 판정 |

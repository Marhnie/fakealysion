# BT1~BT3 카드 효과 검증 (배치 1)

검증 방식: 인쇄된 한국어 문장 대조 후 실제 경로(queueTriggersForStack / emitGameEvent / effectiveDP / hasKeyword / 진화·등장 코스트 함수)로 Node 보드를 구성해 상태를 단언. 하네스: 스크래치패드 b1_*.mjs. 수정 스크립트/훅: `src/cards/shard45.js` + 공통 수정(state.js/effects.js/main.js).

주요 원인 분류: (1) 【자신/상대/서로의 턴】 아래 지속·이벤트 효과가 일회성 스크립트로만 컴파일되어 실제로는 실행되지 않음, (2) 조건/대상 필터 누락(블로커를 갖지 않은, 대상 DP 조건, "이 턴 진화했다면"), (3) N마리 대상 중복 선택, (4) 패의 이 카드 진화/등장 코스트 감소 미구현.

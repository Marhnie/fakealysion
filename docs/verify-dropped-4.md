# 누락 문장 감사 — 배치 4 (102 세그먼트)

조치 요약: 다른 에이전트의 범용 개선(capPer/tail 문장/조그레스/playPaid 등)으로 8건 자동 해소, 나머지는 아래 범용 추가(effects.js compileS13 + runOne) 및 `src/cards/shard13.js` 카드별 스크립트/HOOKS.
감사 도구 수정: dropdump가 `lookupCardSpecific(id, tags)`에 본문을 넘기지 않아 `@needle` 키(예: shard6 SC 스크립트)를 미처리로 오판 -> 본문 전달로 수정. 결과 배치 4는 dropped 0.

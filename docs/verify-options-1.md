# 옵션 카드 영역 검증 — batch 1 (265장)

사용자 보고: "옵션이 배틀 에어리어만 참조하는 것 같은데". 각 옵션을 실제 S/E 함수로 (양측 배틀 에어리어 · 진화원 · 패 · 트래시 · 덱 · 시큐리티가 채워진) 시나리오에서 사용해 대상 후보/출처/목적지 영역을 확인했다.

## 발견·수정한 버그 유형
1. **진화원을 보지 않는 조건/대상** (`진화원에 「X」를 가진`, `진화원에 2색 이상인 카드를 가진`, `진화원을 N장 이상 가진`, `N색 이상인`): parseTargetMods/matchesFilter에 srcHas·colorCountMin·srcMin 추가 (generic).
2. **진화원 → 등장 / 패·트래시 → 진화원 아래(비용)** 가 수동 처리(noop/manualCost)이던 것을 자동화 (playFromSources, placeUnderSource 비용).
3. **"디지몬" 대상 후보에 테이머 포함** (rest/unsuspend가 필터가 없으면 배틀 에어리어 전체를 제시).
4. **상대 측 참조 누락**: BT3-102(상대 시큐리티 파기 선택), BT7-098(상대 디지몬 1마리), BT8-101(1마리 -4000 + 자신의 트래시 아머체 수 배율).
5. **양측 시큐리티 비교 조건** (ST7-11) 자동 판정.
6. 데이터 이상: BT5-094 【메인】 머리말 누락.
7. 사용 절차: 색 조건(4-22)은 배틀+육성 에어리어 모두 확인, 사용 코스트 문구(상대 디지몬 수/시큐리티/트래시/진화원 X항체 등) optionBaseCost 반영, 《딜레이》는 배틀 에어리어의 카드를 다음 턴 이후 UI 버튼으로 발동 — 확인 완료. 이 배치에 【카운터】 옵션은 없음(전체 옵션에도 없음).

검증 스크립트: 스크래치 oh.mjs/orun.mjs/b1_targ.mjs. 브라우저(localhost:5588)에서 ST2-15를 패에서 사용 → 자신의 디지몬 선택 → 진화원 선택 → 코스트 없이 등장까지 확인.

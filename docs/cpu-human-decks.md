## 4. 학습에 쓴 방법

1. `src/cpudeck.js`: 사람 통계가 로드되면(`--human-stats`/`loadHumanStats`, 파일 없으면 무시) 생성기가 (a) 카드 prior 에 채택률 보너스, (b) 라인 두께를 사람 곡선 쪽으로, (c) 테이머 ~7·옵션 ~7장 목표로 뽑는다. 사람 덱 → genome 변환(`genomeFromDeck`, 정확히 재현될 때만 사용).
2. `evolve-decks.mjs --human data/human-decks.json --human-stats data/human-deck-stats.json`: 초기 인구 32 중 절반을 사람 덱(학습 분할, 정확 변환 8개)과 그 변이체로 시드, 세대 건틀릿에 사람 덱 3개 추가, 최종 재평가 건틀릿에 사람 덱 12개 추가. **홀드아웃 분할은 검증 전용**. 사람 덱과 해시가 같은 덱은 출하에서 제외(2개 제거).
3. 실행: 시드 7, pop 32, reps 2, CPU `hard`, 66세대, 30.3분(첫 실행이 gen 21 에서 워커 메모리 부족으로 죽어 `--resume` + `--max-old-space-size=6144` 로 이어감). 세대 최고 적합도 0.71(gen0) → 0.79(gen10) → 0.81(gen30) → 0.85~0.90(gen40~66), 평균 0.49 → 0.66. 예외/스톨 0.
4. 출하: 재평가 상위 중 색 ≤2, 색 조합별 최대 3개(28덱, 10개 색 조합), 파일 최상위에 `source: human-seeded`(덱 항목 스키마는 그대로). 사람 덱 원본은 CPU 덱으로 출하하지 않았다.

## 6. 한계 / 정직한 평가

- **사람 시드로도 수렴 결과는 같은 방향**: 진화가 다시 레드 듀크몬 계열, 테이머/옵션 거의 없음(1.2장), Lv3/4 두꺼운 덱으로 끝났다. 사람 prior/시드는 초기 인구를 개선했으나(gen0 최고 0.71) CPU 자기대전 적합도가 옵션/테이머를 못 쓰는 CPU 의 약점을 그대로 보상한다. 「사람다운」 덱이 목표라면 테이머/옵션 최소 장수 제약이 별도로 필요하다.
- 승률은 hard(탐색 없는 휴리스틱) CPU 대 CPU 결과이며 사람 플레이 승률이 아니다. 진화 덱은 학습 때 사람 학습분할 덱과 싸웠고 검증은 홀드아웃(다른 덱)으로 했지만 같은 대회 풀에서 나온 분할이라 아키타입은 겹친다.
- 코퍼스는 Limitless 한 곳(소규모 지역 대회 다수)이며 상위 입상 덱 비중은 41%(1,080/2,608)뿐. 대표성/메타 편향이 있다. 다른 출처는 미시도.
- 사람 덱의 52%가 수동 fallback 카드를 포함해 시드/건틀릿에서 제외되어, 실제 인기 카드(아스나 등 테이머, 옵션)를 쓰는 덱이 과소대표된다.
- 시드로 정확 변환된 사람 덱은 8개(변환은 라인 재구성이 정확히 재현될 때만 허용)라 시드 다양성이 제한적이다.
- 통제 실험(사람 시드 없는 재진화)은 하지 않았다. 「사람 시드가 성능을 올렸는가」는 이번 자료로 단정할 수 없고, 이전 진화(36세대)와 비교한 절대 강도(이전 CPU 덱 대 83.6%)만 확인했다(세대 수/시드가 달라 인과 비교는 아님).

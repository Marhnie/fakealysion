## 3. 시나리오 쪽 오류였던 것 (엔진 정상, 참고)
- 보안 카드/방어 카드가 DP3000 피요몬이라 공격자와 무승부 → 체크 1회로 끝남 (공격 DP를 올려 해결)
- 옵션의 색 조건(4-22, 다색 옵션은 모든 색 필요), `[턴에 1회]` 표시는 UI/cpusim의 pending 처리부(main.js runPendingScript)가 하므로 드레인 루프에서 재현해야 함 (lib-s1.mjs에 반영)
- "DP 0이 되어 소멸"은 배틀/`deleteStack` 직접 호출이 아니라 DP 감소로 시뮬레이션해야 함
- 진화 드로우(진화 시 1장)가 손패/덱 카운트에 섞임, 옵션 사용 코스트가 메모리에 섞임

## 1. G0 — 이미 적용된 부여가 나중에 「효과를 받지 않는다」가 되면 꺼진다 (Q6354, 6361, 6840, 7047, 7064, 7070)
- 원인: DP/키워드 부여가 합산값(`tempDP`, `keywords`)으로만 저장되어 출처를 알 수 없었다.
- 수정(`src/state.js`): `grantGate`가 상대 효과 출처의 부여를 `stack.applied`(종류/수치/만료/출처 카테고리)에 기록. `settleDeferred` 는 먼저 `suspendApplied` 로 현재 면역인 기록을 되돌려(DP -값, 키워드 삭제, S어택 수치 차감, 어택 금지 해제) `stack.deferred`(기존 15-15-5-2 기록)로 옮기고, 면역이 끝나면 기존 루프가 원래 만료 기한으로 다시 적용한다. 읽기 경로(effectiveDP/hasKeyword/securityAttackBonus/어택 판정/s3Flag) 전부에서 호출. 턴 종료 시 만료된 기록은 정리. 자기 쪽 효과는 영향 없음, `fromCategory`(디지몬 효과만 무효 등)는 출처 카테고리별로 판정.
- 시나리오 9개 통과(`qa-gaps-g0`). 기존 `test-immune-grants.mjs`(95) 유지, `qa-slice6-d` G0 의 xfail 제거.

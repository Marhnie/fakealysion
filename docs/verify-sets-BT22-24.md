# 세트 검증 로그: BT22 / BT23 / BT24 (batch 8)

방식: 인쇄 텍스트와 컴파일 결과를 문장별 대조하고, 실제 S/E 함수로 만든 노드 보드에서 트리거·감시자·지속효과·비용·조건 양쪽 진리값을 실행해 결과 상태를 확인.
하네스: scratchpad `b8_*.mjs` (b8_dump: 세그먼트별 컴파일/배선 덤프, b8_smoke: 437개 세그먼트 실행 스모크, b8_t*: 시나리오).
대상: BT22-/BT23-/BT24- 카드 중 다른 docs에 이미 기록된 카드를 제외한 159장. (기존 docs 표기 카드 148장은 「기존검증」으로 건너뜀)

## 수정 사항 요약 (원인 분류)
| 분류 | 내용 | 조치 |
|---|---|---|
| 감시자 미배선 | 「~했을 때」가 제너릭 감시 파서에 맞지 않아 【자신/서로의 턴】 효과가 절대 발동하지 않음 (링크했을 때, 진화원 증가, 소멸/이탈/레스트/액티브/어택/트래시 진화 등) | shard38 HK(events/onLeave) + 이벤트 본문만(“…때,” 뒤) 컴파일하는 자동 스크립트 |

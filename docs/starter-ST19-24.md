# 스타터 덱 ST19~ST24 카드 효과 전수 검증

검증 방법: 카드 원문(effectKo / inheritedKo)을 문장 단위로 읽고, Node 하네스에서 실제 경로(main.js scriptFor: 개별 스크립트 → compileToScript, 트리거는 queueTriggersForStack / emitGameEvent / 시큐리티 체크, 계속 효과는 effectiveDP / hasKeyword / preventLeave 등)를 스크립트된 선택으로 실행해 결과 상태를 확인했다. 브라우저에서 ST23 vs ST24, ST20 vs ST22 스타터 덱으로 전체 게임을 진행해 로그를 확인했다.

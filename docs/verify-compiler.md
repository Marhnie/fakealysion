# 범용 텍스트 컴파일러(compileToScript) 검증 로그

방법: `S.parseEffectSegments`로 카드별 세그먼트 전체를 덤프(카드별 스크립트가 있는 것은 제외, 자신/상대/서로의 턴 세그먼트는 `parseWatcherTrigger().effect`만 사용) → op/패턴별로 군집화 → 원문 대비 스크립트 의미 확인 → 컴파일러 수정.
덤프 도구: 스크래치패드 `cv/dump.mjs`, `cv/samp.mjs`, `cv/show.mjs`, `cv/cost.mjs`. 덤프 규모: 5262 세그먼트(컴파일 성공 약 4960).

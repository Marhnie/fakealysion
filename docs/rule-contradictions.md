## 1. 이번 검증 방법과 결과

1. 룰북을 장별로 읽고 코드와 대조(6개 상세 문서).
2. Node에서 실제 `S`/`E` 함수를 호출하는 스크래치 재현(진화·조그레스·시큐리티 체크·턴 시작/종료 등).
3. `node scripts/soak.mjs 30` (30게임, 460턴, 1450액션): **distinct errors 0**.
4. `node scripts/audit-effects.mjs`: 효과 커버리지 100%.
5. 실제 브라우저(http://localhost:5588, `window.__dbg()`)에서 새 게임 → 멀리건 → 선공 P2의 첫 턴(드로우 없음) → 메인 페이즈에서 "다음 페이즈" 버튼 비활성 확인 → 패스 → 메모리 상대측 3(P1 시점 +3), P1 드로우 확인. 콘솔 오류 없음.

수정된 항목은 상세 문서에서 "수정됨"으로 표시되어 있다(약 60건: 시큐리티 세팅 순서, 선공 선결정, 투항, 지불 불가 코스트 차단, 육성 에어리어 효과 제한, 메인 페이즈 진행 중 행동 차단, 시큐리티 체크 중 어택 소멸, 【시큐리티】 오컴파일 331/52개 구절, DP 없는 디지몬 룰체크, 키워드 12종 신규 구현 등).

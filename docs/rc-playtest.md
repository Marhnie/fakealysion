# RC 플레이테스트 (실제 UI 구동) 결과

방법: 브라우저에서 실제 UI로 진행. 클릭은 `click()`/실제 마우스 클릭, 드래그는 HTML5 DnD 이벤트(도구의 마우스 드래그는 dragstart를 발생시키지 못해 합성 DragEvent 사용). 봇: `scripts/uibot.js` (`await import('/scripts/uibot.js')` 후 `bots.newGame(덱1,덱2)`, `bots.run(N)`).
덱: ST1테스트A/B, UI레드혼합(Lv3-5 디지몬+테이머+옵션, 덱빌더 UI로 제작), UI블루키워드(재밍/회피/블로커/속공).
게임: 총 8판 (승부 7판 + 투항 1판). 멀리건(실제 클릭), 부화, 육성→배틀 이동, 카드 드래그 등장/진화(디지타마 위 진화 포함)/옵션 사용, 어택(플레이어/디지몬 드롭), 블록(실제 클릭), 시큐리티 체크, 효과 프롬프트, 《회피》 대체효과 프롬프트, 패스, 턴종료 효과, 투항 확인창.

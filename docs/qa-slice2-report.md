## 분류 방법 (정직한 공개)

- Q1751~Q2470 (약 297건)은 카드 한국어 효과 텍스트를 보면서 사람이 직접 분류했다.
- 나머지 816건은 **키워드 휴리스틱**(정의/의미를 묻는 질문 = R, 그 외 = T)으로만 분류했다. 개별 검토하지 않았으므로 T/R 경계는 부정확할 수 있다.
- `docs/qa-slice2-classification.json` = {qid: 'T'|'R'|'N'}.
- 개별 시나리오는 T 중 효과 해결/타이밍/비용/색·진화원 판정 위주로 우선 작성했다. T의 대다수(약 930건)는 **시나리오를 만들지 못했다** (검증되지 않음).

## 수정한 엔진 버그

1. **Q1759/Q1760 (BT8-074 / BT8-079 진화원 효과)**: "덱 위 N장 오픈 후 나머지 파기"가 `deckDiscard` 이벤트를 발생시켜 「덱이 파기되었을 때」 감시 효과(메모리+1)가 잘못 유발됨. 원인: `state.js resolveReveal`, `effects.js runRevealPick`가 나머지 파기 시 일반 덱 파기와 같은 이벤트를 발행. 수정: 두 지점에 `viaOpen:true`를 싣고 감시 조건(`state.js` 「덱이 파기되었을 때」 파서)에서 제외. (「이 카드가 덱에서 파기되었을 때」 옵션 카드 계열은 그대로 유지.)
2. **Q1782 (BT8-102 사마디·샨티)**: 이미 레스트인 상대 카드를 골라도 "이 효과로 레스트한 카드는 액티브가 되지 않는다"가 걸림. 수정(`shard1.js`): 효과 시점에 액티브였던 카드에만 다음 액티브 스킵 부여.
3. **Q1803 (BT9-012 그레이몬X 진화원 효과, P-072 동일 구현)**: "Lv.이 같은 카드 2장"을 **최상단 카드와 같은 Lv.**로 구현했음(정답은 진화원 카드끼리 같은 Lv.). 수정(`shard1.js survive`에 `comboOk` 추가, `graySurvive`).
4. **Q1862/Q1863 (BT9-071 드라큐몬)**: 「…카드 1장을 패에 추가하고, 1장을 파기한다」의 두 번째 "1장"이 필터 없이 아무 카드나 허용. 수정(`effects.js` revealPick 컴파일러): 개수만 적은 다음 스텝은 첫 스텝의 카드 조건을 이어받음. 같은 형식인 EX3-055, BT15-096, BT24-066도 함께 정정됨(정답 미확인 — 같은 문형이라 동일 적용, 개별 공식 Q&A 미확인).
5. **Q1873 (BT9-080 라구엘몬)**: 시큐리티 1장 이하일 때 "대신 …등장시킬 수 있다"가 강제되어 기본 효과(퍼플/옐로 DP6000 이하)를 못 쓰던 문제. `src/cards/shard62.js` 신규(등록: `index.js`): 천사형 후보가 있을 때만 확인하고, 아니면 기본 효과 실행.
6. **Q1897 (BT9-094)**: `destroySum`(DP 합계 상한 소멸)에 「DP 소멸 효과의 상한+1000」이 적용되지 않음. 수정(`effects.js`): `stat==='dp'`일 때 `S.dpDestroyCapBoost` 가산.

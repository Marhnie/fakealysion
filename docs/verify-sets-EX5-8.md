# 세트 EX5~EX8 카드 효과 검증 (batch 11)

방법: 카드별로 인쇄 문구(effectKo/inheritedKo)를 컴파일 결과와 대조하고, 실제 S/E 함수(queueTriggersForStack/emitGameEvent/deleteStack/resolveSecurityCheck/effectiveDP/hasKeyword 등)로 만든 보드에서 스크립트 선택지를 넣어 결과 상태를 확인. 기존 docs에 이미 등장한 110장은 기존검증으로 건너뜀.

## 수정 요약 (계열별)
| 분류 | 내용 |
|---|---|
| 컴파일러 | 「(비어 있는) 육성 에어리어에 코스트 없이 등장」 필터 소실/배틀 에어리어로 등장 (EX5 데바 9장 외 BT15/16/18/EX10 등 공통), 「배틀로 …만을 소멸시켰을 때」 감시 |
| 데이터 정규화 | 「Nsp」->「NSp」(32장), 「나이트 크로우」->「나이트 클로」(14장): 인쇄 문구와 철자가 달라 진화조건/필터 전부 불일치 |
| 상시 효과 | DP/키워드/S어택 조건 (상대 디지몬 수, 레스트 상태, 상대 DP, 전부 부여, 진화원 수·색) 미구현분 훅 추가 |
| 대체 효과 | 이탈/소멸 방지(EX5-018/073, EX6-030/042, EX7-027) |
| 트리거 | 이벤트 훅(진화원 증가, 시큐리티 체크/감소, 상대 패 파기, 어택 대상 변경, 등장 시 진화 시 효과 발휘 등) |
| 코스트 | 등장/진화 코스트 감소 문구 |
| 스크립트 | EX5-041/064/073, EX7-013/037, EX8-015/043/065/067 |

파일: src/cards/shard41.js (신규), src/effects.js(compilePlayFree, playFree op), src/state.js(playFreeToRaising, contGrantCond, 데이터 정규화, 감시 패턴, 일반 진화원 파기 예외 제거).

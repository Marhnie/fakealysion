# EX1~EX4 카드 효과 검증 로그 (batch 10)

방식: `S.CARDS[id].effectKo/inheritedKo`를 문장 단위로 대조 → 실제 S/E 함수로 보드를 구성(양측 필드/패/트래시/시큐리티/메모리)하고 main.js와 같은 경로(트리거 큐잉 → lookupCardSpecific/compileToScript → runScript, 감시자 이벤트, HOOKS, 지속 효과 effectiveDP/hasKeyword)로 실행해 결과 상태를 단언. 참/거짓 분기 모두, 자신/상대 턴, 턴 1회, "그 후" 순서, 대상/영역을 확인.
하네스(scratchpad): `b10lib.mjs`(fixture/헬퍼) + `b10_A*/B*/C*.mjs`. 카드별 스크립트/훅은 `src/cards/shard39.js`.
다른 문서에 이미 OK/수정/기존검증으로 기록된 카드는 건너뜀(EX1~EX4 295장 중 96장).

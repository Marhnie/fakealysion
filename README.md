# 디지몬 카드게임 시뮬레이터

브라우저에서 마우스(드래그 앤 드롭)만으로 플레이할 수 있는 디지몬 카드게임(Digimon Card Game) 2인 대전 시뮬레이터입니다. 실제 카드 데이터베이스와 공식 종합룰북을 기반으로 게임 규칙과 카드 효과를 최대한 자동화하는 것을 목표로 합니다.

프레임워크 없이 순수 JS(ES 모듈)로 작성되어 있고, 빌드 과정 없이 정적 파일만으로 동작합니다.

## 실행 방법

Node.js가 설치되어 있으면:

```bash
npx serve .
```

이후 안내되는 주소(기본 `http://localhost:3000`)로 접속하면 됩니다. Claude Code의 미리보기 도구를 쓰는 경우 `.claude/launch.json`에 등록된 `digimon-sim` 설정(포트 5588)을 그대로 사용하면 됩니다.

## 주요 기능

- **드래그 앤 드롭 플레이**: 손패 카드를 배틀 에어리어나 자신의 디지몬 위로 드래그하면 등장/진화, 옵션 카드 사용까지 코스트 자동 계산으로 처리됩니다. 공격도 상대 배틀 에어리어로 드래그해서 선언합니다.
- **카드 효과 자동화**: 카드 원문(【등장 시】/【진화 시】/【소멸 시】 등)을 파싱해 트리거를 큐잉하고, 자주 나오는 패턴은 자동으로 해석·적용합니다. 진화원(進化元)으로 깔린 카드의 상시 효과(계승 효과)도 함께 계산합니다.
- **시큐리티 배틀 시각화**: 공격/디지몬 배틀/시큐리티 체크 결과를 카드 대 카드 비교 UI로 보여줍니다.
- **3D 테이블탑 뷰**: CSS 3D perspective로 필드를 기울여, 실제 테이블에 마주 앉아 카드를 놓는 듯한 느낌을 줍니다.
- **덱 빌더**: 카드 검색·구성·저장이 가능한 별도 화면(4장 제한/메인 50장/디지타마 5장 등 공식 구성 규칙 검증 포함).
- **공식 한글 용어**: UI 문구를 한글판 공식 명칭(육성 페이즈, 시큐리티, 진화원 등) 기준으로 맞춰뒀습니다.

## 모바일(터치) 조작

드래그 없이 탭만으로 전부 플레이할 수 있습니다 (PC의 드래그&드롭도 그대로 동작). 세로/가로 화면 모두 지원.

- **카드 탭** = 선택 + 하단 시트에 카드 정보 표시 (시트의 글을 탭하면 펼침, ✕로 선택 해제)
- **등장/사용**: 핸드 카드 탭 → 시트의 `▶ 등장` 또는 초록색으로 빛나는 배틀 에어리어 빈칸 탭
- **진화·버스트·어플합체**: 핸드 카드 탭 → 초록 테두리로 표시된 내 디지몬(육성 에어리어 포함) 탭 (진화 방법 선택창이 뜨면 탭으로 선택)
- **링크**: 핸드 카드(또는 배틀 에어리어의 내 디지몬) 선택 → 대상 디지몬의 초록색 🔗 배지 탭
- **조그레스/DNA (룰 8-2)**: 〔조그레스〕가 있는 핸드 카드를 탭(또는 드래그)하면 재료가 될 수 있는 내 디지몬이 보라색으로 빛나고(`🧬재료`), 시트에 `🧬 조그레스 진화 (N조합)` 버튼이 생김. 버튼·재료 탭·재료 위로 드롭 중 무엇이든 조합 선택창(`X + Y → Z`, 코스트·메모리 변화 표시)이 열리고, 조합의 큰 버튼을 누르면 진화. 재료를 먼저 탭하면 `🧬 조그레스 가능: <핸드 카드>` 버튼이 뜸. 조건이 안 맞으면 이유(필요 조건)가 토스트로 표시됨. (기존 `조그레스 상대 선택` 방식은 제거됨)
- **공격**: 액티브 내 디지몬 탭 → `⚔ 공격`(대상 목록에서 선택) 또는 상대의 빨간 테두리 디지몬/상대 헤더(P1·P2 이름줄)를 직접 탭
- **딜레이/트레이닝/⚡메인**: 해당 디지몬 탭 → 시트의 버튼
- **육성 페이즈**: 디지타마 더미 탭 = 부화, 육성 에어리어 카드 탭 = 배틀 이동
- **덱 빌더**: 카드 탭 = 1장 추가, 내 덱의 카드 탭 = 1장 제거, `내 덱 ↓`로 덱 목록으로 이동
- 상단 바는 턴/페이즈/메모리·다음 페이즈·패스·투항, 로그는 오른쪽 아래 `◀ 로그` 버튼

## 카드 효과 자동화 현황

카드 원문을 규칙 기반으로 컴파일해 적용하는 방식이라, 세트별로 커버리지가 다릅니다. 현재 **BT1, EX1, ST1, ST2, ST3**는 텍스트 컴파일 기준 자동 처리가 거의 완비되어 있고, 그 외 세트의 카드는 자동 처리가 안 되는 효과 문구가 있으면 화면 하단 "발동 대기 중인 효과" 목록에 원문 그대로 표시되며, "범용 도구" 패널로 수동 처리할 수 있습니다.

링크(링크)·오버플로우(오버플로우) 등 최신 메커니즘도 엔진에 구현되어 있습니다. 다만 아츠진화(DUAL 카드)는 현재 카드 데이터베이스에 실제로 존재하는 카드가 없어 검증되지 않은 스텁으로만 남아있습니다.

## 효과 가시화 (누구의 효과가 무엇을 했는지)

- 효과 처리 중 남는 로그에는 출처(카드·소유자·【태그】)가 붙고, 로그에서 카드명을 누르면 카드 정보가 열립니다.
- 효과가 끝나면 화면 하단(폰: 전체 폭 시트)에 **효과 처리 카드**(출처 카드, 인쇄 효과문, 결과 목록, 메모리 변화)가 뜨고, 연쇄는 1/3 식의 이전/다음으로 넘겨 봅니다. 상대측 카드에 피해를 준 효과는 붉은 경고 배너가 붙습니다.
- 표시 시간은 카드 하단 셀렉트(짧게 2초/보통 5초/길게 10초/수동 확인, 기본 5초)로 설정하며, 자기 자신에게만 영향인 효과는 최대 2초 후 접힙니다(접히면 효과 N건 칩으로 다시 열 수 있음).
- 영향받은 카드에는 6초간 🎯 배지와 색 링, 소멸한 카드는 같은 구역에 유령 타일(눌러서 닫기)이 남습니다.
- 오른쪽 패널의 **효과 기록** 탭에 최근 50건이 최신순으로 쌓이며, 항목을 누르면 인쇄 효과문이 펼쳐집니다.
- 엔진은 그대로이며 표현만 추가됩니다(state.fxHistory, effects.js runScript / state.js fxNewRec, fxCommit). soak 등 자동 테스트는 UI에 의존하지 않습니다.

## 효과 발동 이펙트 (VFX)

- 효과가 발동하면 화면 중앙에 **「【등장 시】 발동! 카드명」 배너**가 스치고, 출처 카드가 제자리에서 확대되며 링·광선·불꽃 파티클이 터집니다(보드에 없는 카드는 중앙에 플립 인). 색은 태그별: 등장=금, 진화=청록, 어택=적, 소멸=보라, 시큐리티=주황, 메인/옵션=흰색, 《키워드》=녹색, 턴 시작/종료=청록(틸), 딜레이=자홍, 진화원(상속) 효과=은색.
- 결과별 연출: 소멸(적색 플래시·흔들림·파편), 패로/덱으로 되돌림(위로 스윕), DP 증감(녹색 ▲ +N / 적색 ▼ -N), 드로우·패 추가(카드가 패로 날아감), 메모리 변화(게이지 펄스 + 떠오르는 숫자), 시큐리티 파기(파일 섬광 + 금 간 카드 뒷면), 키워드·효과 부여(🛡), 레스트/액티브(회전 글로우).
- 어택/배틀은 state.log 줄을 읽어 공격자 돌진(잔상), 충돌 스파크, DP 비교 숫자, 승자 플레어를 보여줍니다.
- **설정**: 효과 처리 카드 하단과 '효과 기록' 탭의 `이펙트` 셀렉트(화려하게 / 보통 / 끄기, 기본 화려하게, localStorage `digimon_fx_vfx`). 시스템의 '동작 줄이기(prefers-reduced-motion)'가 켜져 있으면 저장값이 없을 때 끄기가 기본입니다.
- 구현: `src/fx.js`(버스 `fxEmit(kind, payload)` — main.js의 fxSync/render가 호출) + `src/fx.css`. 본문 밖 `#vfx-root` 오버레이(pointer-events:none, 보드 위·모달 아래, 배너/숫자만 모달 위)에 풀링한 DOM과 CSS transform/opacity 키프레임만 사용하고 동시 요소 수를 제한하며(폰은 파티클 절반), 엔진은 기다리지 않는 순수 표현이라 soak 등 자동 테스트와 무관합니다.

## 덱 빌더 검색·필터·미리보기

- 검색창은 이름·카드번호·특징·효과·진화원 효과·진화 조건·색 이름(옐로/퍼플 등)까지 전부 검색합니다. 공백=AND, `"구문"`, `-제외`, `a|b`(OR), 대소문자·띄어쓰기 무시. 범위 선택(전체/이름/특징/효과/진화원 효과) 가능.
- 필터 패널(접이식): 종류, 색(+단색만), Lv, 코스트/DP/진화 코스트 범위, 특징(자동완성), 키워드(《》), 효과 타입(【】), 팩/세트, 레어도, 내 덱만, 한도 찬 카드 숨기기, 정렬. 마지막 필터 상태는 localStorage에 저장됩니다.
- 카드 클릭 = 미리보기(PC 우측 패널 / 폰 하단 시트, ◀ ▶ 로 결과 넘겨보기, Esc 닫기). 타일의 ＋ 버튼, 더블클릭, 길게 누르기 = 바로 추가.
- 검색 로직은 `src/dbsearch.js`(순수 함수), 테스트: `node scripts/test-dbsearch.mjs`.

## 데이터 출처

카드 데이터는 [dgchub.com](https://dgchub.com)의 공개 정적 JSON을 가공해 사용합니다(`scripts/build-cards.mjs`). 게임 규칙은 반다이남코 공식 종합룰북(일본어판)을 기준으로 구현했습니다.

## 알려진 한계

- 아츠진화(Arts Digivolve): 실제 DUAL 카드가 데이터에 없어 미검증 상태입니다.
- BT1/EX1/ST1-3 외 세트는 카드 효과 자동화 커버리지가 낮을 수 있습니다 — 수동 처리 패널로 보완하며 플레이합니다.

## 패러렐(대체 일러스트) 카드

- 패러렐 카드는 룰상 **같은 카드 넘버 = 같은 카드**(2-12-1)이므로 게임 로직은 일반 카드 번호만 사용하고, 패러렐은 **일러스트/레어도 변형**으로만 취급합니다. 동일 넘버 4장 제한(예외 50장 등)은 패러렐 포함 합산 그대로입니다.
- 데이터: `node scripts/build-parallels.mjs` → `data/parallels.json` (카드번호별 변형 목록, 약 400KB, 2004종). 로드 후 `S.PARALLELS`.
- 덱 빌더: 카드 미리보기의 "일러스트 선택"에서 덱에서 쓸 아트를 고르면 덱 JSON의 `art: { "BT1-009": "BT1-009_P1" }`로 저장됩니다(구버전 덱과 호환). 타일의 `🎨×N`은 패러렐 종류 수, `패러렐` 배지는 대체 아트 사용 중 표시. 필터: "패러렐 있음", 레어도 필터는 패러렐 레어도(SR/SEC 등)도 매칭.
- 게임: 시작 시 `players[p].art`에 복사되어 `S.artUrl(state, p, cardId)`로 그 플레이어의 카드 이미지만 바뀝니다. 이미지 로드 실패 시 일반 아트로 자동 대체.
- 검증: `node scripts/test-parallels.mjs`
